# シンプル WinRoll（Simple-WinRoll）

ウィンドウのタイトルバーを右クリックすると、そのウィンドウを細いバー1本に「巻き上げ」る Windows 11 向けの常駐ツールです。
もう一度右クリックすると元に戻ります。

かつての Mac OS の WindowShade や、Windows 用フリーソフト **WinRoll** と同じ使い心地を、今の Windows で目指しています。

## WinRoll への感謝

私は長年、Wil Palma さんの [WinRoll](http://www.palma.com.au/winroll/)（2003–2004）を愛用してきました。
100% アセンブリ言語で書かれた小さくて速いツールで、公式ページがなくなったあとも、Windows 11 でぎりぎり動かしながら使い続けていました。

ただ、最近のアプリはウィンドウの最小サイズを自分で決めていたり、タイトルバーを独自に描いていたりするものが増えました。そのため、巻き上げてもタイトルバーだけになりきれず、中途半端にウィンドウが残ってしまうことが多くなってきました。

そこで、長年お世話になった恩返しの気持ちを込めて、今の Windows でも同じように使える同じタイプのソフトを作りました。
WinRoll のコードは一切使っていない、新しく書き直した別のソフトウェアです。それでも、操作の考え方はすべて WinRoll から受け継いでいます。ライセンスも、敬意を込めて WinRoll と同じ系統の zlib ライセンスにしました。

Wil Palma さん、素晴らしいツールを本当にありがとうございました。

## ダウンロード

[Releases](https://github.com/KinaPPP/simple-winroll/releases) から `simple-winroll-v◯_◯_◯.zip` をダウンロードして、好きな場所に展開してください。
インストールは不要です。`simple-winroll.exe` を起動するとタスクトレイに常駐します。

初回起動時に「Windows によって PC が保護されました」と表示された場合は、「詳細情報」→「実行」で起動できます（署名していない個人製ソフトのためです）。

## 使い方

| 操作 | はたらき |
| --- | --- |
| タイトルバーを右クリック | ウィンドウを巻き上げる |
| 巻き上げたバーを右クリック／ダブルクリック | 元に戻す |
| 巻き上げたバーをドラッグ | 移動（戻したときに位置が反映） |
| 巻き上げたバーで Alt＋F4 | 元に戻してからアプリを閉じる |
| タイトルバーを中クリック | 半透明にする／元に戻す |
| Shift＋タイトルバーを左クリック | いちばん後ろへ送る |
| 閉じるボタンを右クリック | いちばん後ろへ送る |
| 閉じるボタンを中クリック | 常に手前に表示する／やめる |
| 最小化ボタンを中クリック | タスクトレイへ最小化する |
| Alt＋タイトルバーを右クリック | すべて巻き上げる（バー側ではすべて戻す） |
| Alt＋最小化・最大化・閉じるを左クリック | すべてのウィンドウに適用する（閉じるは確認あり） |
| タスクバーのボタン | 前面に出す／もう一度押すと元に戻す |
| トレイアイコンを右クリック | 設定／操作一覧／すべて元に戻す／終了 |

中ボタンの操作は、すべて「Shift＋右クリック」でも代用できます。

## 特長

- **どのアプリでもタイトルバーだけになる**：ウィンドウの高さを縮める方式ではありません。元のウィンドウを一時的に隠し、同じ位置・同じ幅で細いバーを表示します。そのため、アプリ側の最小サイズに邪魔されません。
- **分かりやすいバー**：アプリのアイコン・アプリ名・ウィンドウタイトルを表示します。色は Windows の「個人用設定 → 色」のアクセントカラーに合わせます。
- **タスクバーにまとまる**：巻き上げたバーは、元のアプリと同じタスクバーのボタンにまとまります。
- **ウィンドウが行方不明にならない**：巻き上げ・トレイ・半透明はどれも、終了時・シャットダウン時に元に戻してから終わります。強制終了などで落ちた場合も、次回起動時に元の位置・サイズで表示し直します。
- **WinRoll のモードをすべて搭載**：半透明・最背面・常に手前・トレイへ最小化（アイコン表示／メニューにまとめる）・Alt キーで全ウィンドウに適用。
- **Windows の設定に合わせた半透明**：「個人用設定 → 色 → 透明効果」がオンのときだけ半透明にします（濃さは 80%）。
- **起動したことが分かるスプラッシュ画面**：起動時に約3秒表示します（自動起動のときも）。設定でオフにできます。
- **大きく表示できる設定画面**：設定画面と操作一覧は 100〜200% に拡大できます。
- 単体の exe（約 360KB）で動き、追加のランタイムは不要です。

## 注意

- 管理者権限で動いているウィンドウは巻き上げられません。
- 置き場所は、自分だけが書き込めるフォルダ（例：`%LOCALAPPDATA%\Programs\simple-winroll`）がおすすめです。`C:\` 直下に新しく作ったフォルダは、同じ PC のほかのユーザーも書き込める設定になっていることがあります。
- 二重起動を防ぐ仕組みは、同じユーザー権限で動く別のプログラムからは妨げられることがあります（起動できなくなるだけで、ほかに影響はありません）。

## 安全への配慮

- 外部との通信は一切行いません。
- 必要な DLL は Windows のシステムフォルダ（System32）からだけ読み込みます。
- シンプル WinRoll がタスクマネージャーなどで強制終了された場合も、一緒に起動している見張り役が、隠れたウィンドウを元に戻します。
- 各リリースの ZIP と exe の SHA-256 は、Releases のページに記載しています。

## ビルド方法

Linux の MinGW-w64（`x86_64-w64-mingw32-g++`）で、`src` フォルダ内の `build.sh` を実行します。

```sh
cd src
sh build.sh
```
